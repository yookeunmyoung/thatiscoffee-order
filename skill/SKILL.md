# 단체 주문표 메뉴 바꾸기

단톡방에 공유한 링크(https://yookeunmyoung.github.io/thatiscoffee-order/)는 그대로 두고, **구글 시트의 세 탭만** 바꾼다. 웹페이지 코드, GitHub, PC는 건드리지 않는다. 시트를 고치면 다음에 페이지를 여는 사람부터 새 메뉴가 보인다.

- 구글 시트: "thatiscoffee 단체 주문" (https://docs.google.com/spreadsheets/d/1bWJ_xjTguni2lLAo-67-hqEcTJ4kiTXLZRqx6g9v4Vs/edit)
- 탭 구성 (1행은 머리글, 2행부터 내용)

| 탭 | A열 | B열 | C열 |
| --- | --- | --- | --- |
| 설정 | 항목 | 값 | |
| 메뉴 | 카테고리 | 메뉴 | 가격 |
| 옵션 | 옵션 | 가격 | 표시 문구 |

- "주문", "지난주문" 탭은 주문 기록이다. 절대 건드리지 않는다.

## 1. 메뉴판 읽기

이미지를 모두 읽고 다음을 뽑는다.

- **가게 이름**: 메뉴판에 없으면 사용자에게 묻는다. 지어 넣지 않는다.
- **아이콘**: 업종에 맞는 이모지 하나 (카페 ☕, 국밥·찌개 🍲, 고기 🥩, 중식 🥟, 분식 🍜, 피자 🍕, 술집 🍺 등)
- **메뉴**: 카테고리, 메뉴 이름, 가격(원 단위 숫자, 쉼표 없이).
  - 메뉴판의 구분(식사/사이드/주류 등)을 카테고리로 쓰고, 없으면 2~5개로 묶는다.
  - "9.0"은 9000, "9천"은 9000.
  - HOT/ICE, 소/중/대, 1인분/2인분처럼 값이 다른 변형은 **각각 다른 줄**로 쓰고 이름을 구분한다. 메뉴 이름이 겹치면 안 된다(주문 합산이 이름 기준이다).
  - 시가, 가려진 가격, 읽기 애매한 글자는 추측하지 않는다. 그런 메뉴는 표에서 빼고 "확인 필요" 목록과 참고 문구에 적는다.
- **옵션**: "곱빼기 +1,000", "샷 추가 +500", "포장 할인 -500"처럼 여러 메뉴에 공통으로 붙는 추가 요금만. 체크하면 그 사람의 주문 수량 전체에 곱해진다. 공통 옵션이 없으면 옵션 표는 머리글만 남긴다.
- **옵션 제외 카테고리**: 옵션이 붙지 않아야 하는 카테고리(디저트, 사이드, 주류 등)를 쉼표로.

설정 탭 값:

| 항목 | 값 |
| --- | --- |
| 가게 이름 | (가게 이름) |
| 아이콘 | (이모지) |
| 안내 문구 | 📋 주문 체크표입니다. 🍲 각자 메뉴를 고른 뒤 👇 아래로 내려와 주문 내역을 확인하고, ✍️ 이름(호칭, 별명)을 쓴 다음 📨 "주문 보내기" 버튼을 눌러 주세요 😊 |
| 요청사항 안내 | 업종에 맞게. 카페는 "개별 HOT/ICE, 시럽 등", 식당은 "맵기, 덜어 먹을 그릇 등" |
| 참고 문구 | 출처와 확인할 점. 예: "2026년 10월 메뉴판 사진 기준입니다. 수육 가격은 시가라 매장에서 확인하세요." |
| 옵션 제외 카테고리 | (쉼표로 구분, 없으면 빈칸) |

안내 문구는 사용자가 정한 문장이다. 두 번째 이모지(🍲)만 아이콘과 같게 바꾸고 나머지는 그대로 쓴다.

## 2. 사용자 확인

시트를 바꾸면 단톡방 사람들이 바로 보게 되므로, 넣기 전에 짧게 요약해 보여 주고 "이대로 넣을까요?"라고 한 번만 묻는다.

- 가게 이름, 카테고리별 메뉴 개수, 옵션
- 확인이 필요한 항목과 처리 방법(뺐음 / 참고 문구에 적음)

## 3. 시트에 넣기

쓸 수 있는 방법에 따라 하나를 고른다.

**A. 구글 시트를 고칠 수 있는 도구가 있을 때** (구글 드라이브·시트 커넥터, 또는 Claude Code의 Chrome 브라우저 도구)
- 설정·메뉴·옵션 탭의 2행부터 기존 내용을 지우고 새 내용을 넣는다. 머리글(1행)은 유지한다.
- 메뉴 줄 수가 줄어든 경우 남은 예전 줄이 없도록 지운다.
- Chrome으로 할 때: 탭 하나씩 열고 A1을 클릭한 뒤 전체 범위를 지우고, 머리글을 포함한 탭 구분 텍스트를 클립보드에 넣어 A1에 붙여 넣으면 칸이 나뉘어 들어간다.

**B. 그런 도구가 없을 때** (휴대폰 Claude 앱 등)
- 탭마다 코드 블록 하나씩, **머리글 포함, 칸 사이는 탭 문자**로 된 표를 준다. 코드 블록은 복사 버튼이 있어 휴대폰에서 복사하기 쉽다.
- 사용자 안내(짧게):
  1. 구글 시트 앱에서 "thatiscoffee 단체 주문"을 연다.
  2. 메뉴 탭에서 A열~C열 머리를 길게 눌러 선택하고 "삭제"(값 지우기)한다.
  3. A1 칸을 길게 누르고 "붙여넣기" 한다. 설정·옵션 탭도 같은 방법.
  4. 한 칸에 몰려 들어가면, 데이터 → 텍스트를 열로 분할(구분자: 탭)을 쓰거나 PC에서 붙여 넣는다.

## 4. 지난 주문 비우기

가게가 바뀌면 전 모임 주문이 화면에 남는다. 사용자에게 주문표 맨 아래 **"새 모임 시작"** 버튼을 누르라고 안내한다(비운 주문은 시트의 "지난주문" 탭에 보관된다). Claude Code에서 명령을 실행할 수 있으면, 사용자가 원할 때 아래로 대신 비울 수 있다.

```bash
curl -sL -X POST -H "Content-Type: text/plain" -d '{"action":"reset"}' "https://script.google.com/macros/s/AKfycbxEUfzQml3QJDycz3InZkNV3T0C5NjrEoXVF8Vh_Tg1YwYJ-O-wMsGL6AfQgm_iCq0l/exec"
```

- 단톡방에 붙일 한 줄, 예: "이번엔 ○○예요. 같은 링크 열고 이름 쓰고 주문 보내기 눌러 주세요 → https://yookeunmyoung.github.io/thatiscoffee-order/"

## 가격만 고칠 때

"아메리카노 4,000원으로 바꿔줘"처럼 일부만 고치면 메뉴 탭의 해당 줄만 고친다(A 방법), 또는 "메뉴 탭 ○행 C열을 4000으로 바꾸세요"처럼 위치를 알려 준다(B 방법). 확인 질문은 생략해도 된다.

## 예전 가게로 되돌리기

시트는 가게별 메뉴를 따로 보관하지 않는다. 자주 가는 곳이면 메뉴 탭을 통째로 복사해 "메뉴_가게이름" 같은 탭으로 남겨 두자고 제안하고, 되돌릴 때 그 내용을 메뉴 탭에 다시 넣는다. 보관용 탭 이름은 "메뉴", "옵션", "설정"과 겹치지 않게 한다.
